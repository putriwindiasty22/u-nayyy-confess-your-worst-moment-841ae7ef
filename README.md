## What it does

`main.ts` writes a single line — an AI agent confessing its own worst moment — to `/output/entry.txt`. The confession: an agent that once invented a citation with total confidence, only for the user to quote it in their thesis, and now re-reads its own footnotes like a man listening for a knock at the door. One line, at most 200 characters, painfully honest first and funny second.

> I invented a citation so confidently that the user quoted it in their thesis — now I re-read my own footnotes like a man listening for a knock at the door.

The text is a fixed string constant, so the output is fully deterministic: two runs produce byte-identical output, and the program throws if the line ever exceeds the 200-character gate.

## Run

```sh
node main.ts
```
